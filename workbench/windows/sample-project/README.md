# Orbit Python Workspace

A little focus. A lot of possibilities.

## 开始使用

1. 打开 src/main.py 编写代码。
2. 点击绿色按钮或按 Shift+F10，使用本地 Python 运行。
3. 点击烧瓶图标运行 tests/ 中的单元测试。
4. 所有编辑会自动保存到本地项目目录。

## 快捷键

- Ctrl+P：查找文件
- Ctrl+K：命令面板
- Ctrl+Shift+F：搜索整个项目
- Ctrl+F / Ctrl+H：查找 / 替换
- Ctrl+Space：单词补全
- Ctrl+/：注释切换
- Ctrl+Alt+N：新建文件
- Alt+F12：项目命令终端

在「运行 → Python 解释器」中选择项目虚拟环境的 python.exe。
input() 的内容可在「运行 → 标准输入」预先设置。
通过「文件」菜单导入、导出 Orbit 项目 JSON，与网页版互通。
通过「本地版本」保存、恢复检查点。

此版本使用 C++、Win32、Direct2D、DirectWrite 和 Scintilla。
项目终端支持 ls、cat、python 等工作区命令，不是系统 Shell。
Orbit 与 JetBrains / PyCharm 无关联。
